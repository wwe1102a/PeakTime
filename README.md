Projectนี้ถูกทำขึนเพื่อแก้ปัญหาเวลาเพื่อนต้องการนัดแล้วนัดชนกับคนอื่น 
จึงมีแนวคิดว่าทำระบบการจองเวลาขึ้นมาเพื่อให้เพื่อนได้รู้ว่าจะสามารถนัดเวลาไหนได้บ้าง
โดยทำเหมือนเว็บจองร้านอาหารทั่วไปๆที่ต้องlog Inเพื่อใช้งานการจองเวลา
Functional requirements
- ผู้ใช้สามารถRegisterได้
- ผู้ใช้สามารถlog inเพื่อเข้าสู่ระบบได้
- เว็บสามารถแสดงปฏิทินการจองอัพเดตแบบReal Timeได้
- เว็บสามารถจองเวลาและรายละเอียดลงในหน้าปฏิทินได้
- ผู้ใช้สามารถจองเวลาได้
